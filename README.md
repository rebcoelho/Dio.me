# 📊 Simulador de Investimentos em Fundos Imobiliários (FIIs)

Este projeto foi desenvolvido como parte de um desafio da **DIO** para aplicar conceitos de Excel na criação de uma ferramenta prática de simulação de investimentos em **Fundos Imobiliários (FIIs)**.  

A planilha permite ao usuário realizar cálculos e projeções sobre aportes mensais, tempo de investimento, taxa de rendimento e dividendos, oferecendo uma visão clara do potencial retorno financeiro.

---

## 🎯 Objetivos do Projeto

- Criar uma ferramenta em Excel para simulação de investimentos em FIIs.  
- Automatizar cálculos financeiros como:
  - Valor total investido  
  - Patrimônio acumulado  
  - Dividendos mensais  
- Auxiliar na tomada de decisão sobre aportes e perfil de investimento.  
- Documentar o processo técnico e compartilhar no GitHub.  

---

## ⚙️ Funcionalidades da Planilha

- **Configurações iniciais**:  
  - Salário do investidor  
  - Percentual sugerido para investimento (ex.: 30%)  
  - Valor do aporte mensal  
  - Tempo de investimento (em anos)  
  - Taxa de rendimento mensal  

- **Cenários de dividendos**:  
  - Projeções de dividendos em diferentes horizontes de tempo (2, 5, 10, 20 e 30 anos).  

- **Perfis de Investidor**:  
  - Conservador  
  - Moderado  
  - Agressivo  

Cada perfil possui uma distribuição sugerida entre diferentes tipos de FIIs:  
| Tipo de FII       | Conservador | Moderado | Agressivo |
|-------------------|-------------|----------|-----------|
| Papel             | 30%         | 32%      | 50%       |
| Tijolo            | 50%         | 35%      | 10%       |
| Híbridos          | 10%         | 8%       | 5%        |
| FOFs              | 10%         | 5%       | 5%        |
| Desenvolvimento   | 0%          | 10%      | 20%       |
| Hotelarias        | 0%          | 10%      | 10%       |

## 🚀 Como Usar

1. Baixe ou clone este repositório.  
2. Abra o arquivo `PLANILHA INVESTIMENTO.xlsx` no Excel.  
3. Configure os parâmetros iniciais (aporte mensal, tempo de investimento, taxa de rendimento).  
4. Explore os cenários e perfis de investimento para visualizar projeções de patrimônio e dividendos.
